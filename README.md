# python-file-management
A basic file management program using Python pathlib

A beginner-friendly file management program built using Python's pathlib module.

Features

Create and manage files.
Perform file operations using pathlib.
Technologies Used

Python
pathlib
How to Run

Install Python.
Download or clone this repository.
Open the project folder in VS Code.
Run the Python file:
python main.py

Learning Objective

This project helped me practice Python fundamentals and understand filesystem operations using pathlib.
